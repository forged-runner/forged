Garmin-Synchronisation: noch nicht verbunden

Die offizielle Garmin Connect Developer API ist keine einfache private Login-Schnittstelle. Garmin beschreibt sie als Developer-Programm für Business-/Enterprise-Anwendungen mit Prüfung und Freigabe. Diese App fragt weder dein Garmin-Passwort ab noch behauptet sie eine Synchronisation.

Bis eine offizielle Integration verfügbar und genehmigt ist, kannst du Läufe manuell eintragen. CSV-/FIT-Import ist in dieser ersten Version noch nicht enthalten.
