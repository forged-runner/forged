## Update 2.0.2 – periodisierte Longruns
Longruns wechseln zwischen locker, progressiv, moderatem Endteil, Marathonpace-Simulation und Entlastung. Jede normale Woche enthält mindestens einen Trainingsreiz; in intensiven Longrun-Wochen wird die Dienstagseinheit reduziert. Entlastungswochen erhalten nur kurze Steigerungen. Wettkampf- und Taperwochen haben Vorrang. Die bestehenden lokal gespeicherten manuellen Plan-Overrides bleiben erhalten und können neue Vorgaben überlagern.
